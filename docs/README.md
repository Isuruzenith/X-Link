## Conventions
- Keep numbered architecture-note filenames stable to preserve existing wikilinks.
- `notes/`: reusable technical notes and research.
- `decisions/`: durable architecture/product decisions (use ADR template).
- `meetings/`: meeting notes and action items.
- `_inbox/`: unprocessed material.
- `_attachments/`: new attachments; existing `assets/` remains intact.
- `_templates/`: templates for consistent notes.

Verify implementation details against current source code. Treat [[99-Vault-Changelog]] as the explicit documentation drift register.
